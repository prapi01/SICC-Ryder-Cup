Step 1: Main Menu
The app has three main sections:
• TODAY GAME / NEXT GAME - Shows scheduled game
• VIEW PREVIOUS GAMES - See past results
• DEMO & TUTORIAL - You are here!
• GAME SETTINGS - Admin functions
💡 Tip: The NEXT GAME button will change to TODAY GAME on the match day. The button is not active until actual game day.
